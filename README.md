# Rohan Singh Portfolio

A static portfolio for Rohan Singh's website and mobile app development services.

## Preview

Open `index.html` in a browser. The page uses plain HTML and CSS; no build step or package installation is required.

## Update the portrait

Replace `rohan-with-laptop.png` with the updated photo, keeping the same filename so the homepage continues to load it.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site will be available at `https://panditrohanujjain-tech.github.io/rohan-singh-portfolio/` after Pages finishes deploying.
